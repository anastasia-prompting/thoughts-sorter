## [0.1.0] - 2026-04-26

### Added

- MVP-раунд 60 секунд: спавн мыслей, поимка, сортировка по трём корзинам
  (`Сделать`, `Сохранить`, `Отпустить`).
- Очки и комбо по правилам ТЗ.
- Экраны: старт, туториал, игра, результаты, статистика, настройки.
- Сохранение прогресса в `localStorage`.
- Визуальная тема `Moon Observatory`: фоны, маскот Cloud Moth и облачные
  пузырьки мыслей в виде PNG-ассетов.
- Полноценный full-browser/full-mobile layout с поддержкой safe-area.
- Автодеплой на GitHub Pages через GitHub Actions.
